# **App Name**: Plagiarism Analyzer

## Core Features:

- Text Input: Text Input: Allow users to input text via a text field or copy/paste.
- Plagiarism Check: Plagiarism Detection: Employ a generative AI tool to compare the input text against a corpus of existing text and determine the percentage of plagiarism.
- Highlighting: Highlight Plagiarism: Display the analyzed text with plagiarized sections highlighted in red. Other text is normal.
- Percentage Readout: Percentage Display: Display the overall percentage of plagiarism detected in the text.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to convey trustworthiness.
- Background color: Very light gray (#F0F2F5), a muted shade of the primary color, to provide a neutral backdrop for the content.
- Accent color: A vivid violet (#BA68C8) is used sparingly, for emphasis and highlights. 
- Font pairing: 'Belleza' for headings (a humanist sans-serif) and 'Alegreya' (a humanist serif) for body text to promote readability and impart a subtle artistic impression.
- Simple, clear icons to represent different file types and actions.
- Clean, single-column layout to focus attention on the text and results.
- Subtle animations during the text analysis process to provide feedback without distraction.
