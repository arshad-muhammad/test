# **App Name**: WordWeaver AI

## Core Features:

- Input Form: User input form for article topic, tone, and format preferences.
- Article Generation: Generates a 6000+ word article based on user input using Gemini 1.5 Pro/Flash and the provided prompt.
- Link Insertion: After each section, use an LLM-powered tool to identify and add 1-2 relevant real-world links from sources like Wikipedia or Forbes.
- Content Display: Displays the generated article content with section headings, paragraphs, and embedded real-world links.
- Export Options: Provides options to copy content, download as .txt or .pdf, and summarize the content to 500 words.
- SEO Optimization: Auto-generates an SEO title and meta description for the article.
- Loading Animation: Loading animation displayed while Gemini generates the article content.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey intelligence and authority.
- Background color: Light gray (#F0F2F5), creating a neutral backdrop.
- Accent color: A muted purple (#9575CD) to draw attention to actionable elements.
- Headline font: 'Space Grotesk' (sans-serif) for a tech-forward look. Body font: 'Inter' (sans-serif) for readability.
- Use clean, minimalist icons from a library like FontAwesome or Material Design Icons.
- Emphasize a clear, hierarchical layout to enhance readability and scannability.
- Incorporate subtle animations on content load and interaction to give a smooth experience.
